# 機電自檢紀錄表（自主檢查表 離線版）

給工地主任隨身帶著用：**不需要網路、不需要伺服器、不需要登入**。
填寫的檢查表只存在自己的手機／平板／筆電裡，填好產生 PDF，到便利商店雲端列印即可。

## 功能
- 55 份檢查表（含 14 份機電設備工程），中文／越南文切換
- 依「工地」分開（工地名稱會印在表上的「工程名稱」）
- 逐項 ○ ✕ ／ 標記、實際檢查情形、缺失複查、手寫簽名
- 「其他檢查項目（自行填寫）」：範本以外的項目可自行新增，會印在表上
- 預覽／列印，列印語言可選中文、越南文、中越對照
- 下載 PDF → 7-ELEVEN ibon、全家 FamiPort 雲端列印
- 備份匯出／匯入（換手機前務必先匯出）

## 水電清查（`water/`）
清豐安居社宅水電施工自主檢查「未做」清查，封面點「🔌 水電清查」進入。
- A～H 棟依現場配置（B C／A D／H E／G F）選棟；B、C、F、G 棟每層 16 間，A、D、H、E 棟每層 15 間
- 第一次進入先確認公司名稱、工地名稱（印在 PDF 表頭；首頁「✎ 修改」）
- 2F～14F：逐間點選戶內 28 項＋公共區域 14 項（✓ 完成、△ 施工中、✗ 缺失、— 不適用），項目比照 Excel「每層檢查表」
- 1F、RF、B1、B2 項目待定（`water/water.js` 的 `PENDING_FLOORS`，有項目後再開放）
- 點 △ 可寫未做原因（快速選項＋自己打字）；✗、△ 都列在缺失追蹤，改善日期、修正紀錄（含填寫人）；PDF／列印為 A4 橫式並印上版次
- 第一次進入填「你的名字」，每一間記下最後填寫人與時間；同事把備份檔傳給管理者匯入，逐間合併（同一間以較新的為準）
- 資料存在裝置的另一個資料庫（`water-check`），不在自主檢查表的備份裡；用水電清查首頁的「匯出備份／匯入備份」
- `water/` 不是由 build_offline.py 從主網站複製的，直接修改即可（改完記得更新 `sw.js` 的 VERSION）

## 自主檢查表只給管理者（`js/owner-lock.js`）
設定管理者帳號密碼後，沒在這台裝置登入過管理者的人，封面看不到「自主檢查表」，網址 `#/self-check` 也會被擋回封面；
封面下方按「🔒 管理者登入」輸入一次帳號密碼，這台裝置之後就不用再輸入（按「登出」可再藏起來）。水電清查不受影響。
```
python tools/set_owner_password.py
```
可改帳號或密碼；只會把帳號與密碼的雜湊寫進 `js/owner.js`（密碼本身不存檔；帳號空白＝取消上鎖），改完記得更新 `sw.js` 的 VERSION 再推上 GitHub。
網站與程式碼是公開的，這是「不讓別人隨手打開」的門鎖，不是加密；填寫的資料本來就只存在各自的裝置。

## 安裝到手機（第一次需要網路）
離線版必須先放在 **HTTPS 網址** 上，手機打開一次後，就會存在手機裡，之後沒網路也能用。
1. 用手機瀏覽器打開離線版網址
   - Android：Chrome →「⋮」→「安裝應用程式」或「加到主畫面」
   - iPhone：Safari →「分享」→「加入主畫面」
2. 主畫面會出現「自檢表」圖示，之後直接點圖示開啟
3. 右上角顯示「✓ 可離線使用」就表示已存到手機

> 筆電也可以用 Chrome／Edge 打開同一個網址，網址列右側會出現「安裝」圖示。

## 便利商店列印
1. 在檢查表按「👁 預覽／列印」→ 選列印語言 →「⬇ 下載 PDF」
2. 7-ELEVEN：用「ibon 列印」App 或 ibon 雲端列印網站上傳 PDF，取得取件編號後到 ibon 機台列印
3. 全家：用 FamiPort 雲端列印上傳 PDF，到 FamiPort 機台列印

（上傳 PDF 到超商列印服務需要網路；沒網路時先存在手機，有訊號時再上傳。）

## 備份
資料只存在這台裝置。**換手機、清除瀏覽器資料、重灌之前**，請按「💾 備份 → 匯出備份檔」，
把 `自主檢查表備份_日期.json` 存到電腦或雲端硬碟。新裝置用「匯入備份檔」即可還原。

## 更新內容（給維護的人）
檢查表範本或主網站填表畫面修改後：
```
python tools/build_offline.py
```
會把最新的範本與畫面複製到 `offline-app`，並更新版本號。再把整個 `offline-app` 資料夾更新到發佈網址，
手機下次連網開啟時會自動換成新版（已填的資料不受影響）。

## 檔案說明
| 檔案 | 用途 |
|---|---|
| `index.html`、`app.css`、`offline-app.js` | 離線版外框（工地、備份） |
| `offline-store.js` | 資料存在裝置（IndexedDB） |
| `sw.js`、`manifest.webmanifest` | 離線快取、安裝到主畫面 |
| `css/`、`js/pages/`、`js/vendor/`、`data/` | 由 build_offline.py 從主網站複製，**請勿直接修改** |
| `icons/` | App 圖示（build_offline.py 自動產生） |

## 字型
列印／PDF 的檢查表使用標楷體：電腦有內建標楷體（Windows、Mac）就用內建的；手機沒有標楷體，
改用 `fonts/tw-kai-subset.woff2`——取自國家發展委員會「全字庫正楷體」（TW-Kai），
依[政府資料開放授權條款](https://data.gov.tw/license)使用，只保留常用字與檢查表用到的字以縮小檔案。
